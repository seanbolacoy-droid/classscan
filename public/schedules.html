1. Upload Timetable

Select a timetable photo or screenshot. ClassScan will extract its text for you to review.

Use the same section name registered for its students.

JPG, PNG, or WEBP only. Maximum file size: 5 MB.

2. Review Extracted Text

Check the recognized text below. OCR may mix up columns or misread some words, so use your original timetable when confirming the start times.

3. Confirm First-Class Start Times

Enter the start time of the first scheduled class for each school day. These are the times ClassScan will use when determining attendance status.

Present: arrival at or before the confirmed start time. Late: arrival after the confirmed start time. The adviser must verify these times before saving.
